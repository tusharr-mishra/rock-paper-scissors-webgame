# Overview

This project is a browser-based implementation of the classic **Rock Paper Scissors** game where the user competes against the computer in real time.

The application was developed as a frontend practice project to improve understanding of:

- JavaScript fundamentals
- DOM manipulation
- Event listeners
- Conditional logic
- UI interaction handling
- Responsive web design
- Frontend project organization

The game provides an engaging and smooth experience while maintaining a lightweight and beginner-friendly codebase.
